# Production Photos

This folder contains the final optimized images used on the live site.

## Rules

- Only place final, production-ready JPGs here.
- Use the established naming convention (see `photos-to-use/enhanced/README.md` and **`photos-to-use/enhanced/photo-inventory.md`** for per-photo sizes and site mapping).
- Do not commit unoptimized or raw files here.

## Recommended Optimization

Before placing files here:
- Correct color and contrast
- Run AI sharpening (Topaz Photo AI recommended)
- Export at appropriate sizes (recommended targets in `photo-inventory.md`):
  - **hero:** 2400×1350 (16:9) — range 1800–2400px wide
  - **story:** 1600×1200 (4:3) — range 1200–1600px wide
  - **card:** 1000×750 (4:3) — range 800–1000px wide
- Use quality 85–90
