# templates

Reusable website templates, UI prototypes, and purchased themes used across COTIB LLC web properties.

---

## Contents

### `index.html` — LLM Chat Interface Prototype

A browser-based chat UI prototype supporting multiple LLM providers. Built with Tailwind CSS (CDN) and Axios.

**Supported models:**
- OpenAI (default)
- Claude Opus
- Gemini 1.0

Use this as a starting point for integrating conversational AI into web projects.

---

### `templatemo_549_business_oriented.zip` — Business Oriented Template

HTML/CSS business website template from [TemplateMo](https://templatemo.com/tm-549-business-oriented).

**Used as the foundation for:** `cotib.com`

Features: Bootstrap 4, parallax scrolling, FontAwesome icons, responsive layout.

---

### `themeforest-Fh93wTIW-soundcast-podcast-responsive-theme.zip` — Soundcast Podcast Theme

Premium WordPress/HTML podcast theme from ThemeForest.

**Intended for:** podcast website builds (e.g., The IT XP).

Features: episode listings, audio player, show notes layout, responsive design.

---

## Usage Notes

- Zip files contain the full template source — extract before use
- Customize brand colors, fonts, and copy before deploying
- Check template licenses for commercial use terms before publishing
