Connect / Reconnect QuickBooks

Last updated: October 6, 2026

This page is the connect / reconnect landing URL for COTIB LLC’s private QuickBooks Online app (GrokIntegration).

What this connection does

It authorizes Grok Bot to access COTIB LLC’s QuickBooks Online company via the Intuit Accounting API for internal bookkeeping (reports, categorization, invoices, bills, payments when Chuck asks).

Who can connect

Only the QuickBooks Online company administrator for COTIB LLC (Charles Betancourt). This is a private, single-company integration.

How to connect or reconnect

  1. Open the OAuth link provided by the Grok Bot / MCP connector setup (Production keys).
  2. Sign in to Intuit and select the COTIB LLC QuickBooks company.
  3. Approve the requested Accounting scopes.
  4. Return to Grok Bot; tokens are stored as environment secrets.

If tokens expire or auth errors appear, run the same OAuth flow again from this reconnect process.
