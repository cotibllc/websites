# cotib.link

Static link hub for every COTIB brand. No build step.

- Files: `index.html`, `styles.css`, `favicon.svg`, `vercel.json`.
- Look follows cotib.com: navy base, brand blue and cyan accents, Outfit and Inter fonts.
- Outbound links carry `utm_source=cotib.link&utm_medium=linkhub&utm_campaign=<brand>`.
- Deploy (not done yet): a new Vercel project with Root Directory `cotib.link`, Framework Preset "Other", and no build command. The cotib.link domain is registered at AWS Route 53.
